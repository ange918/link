Génère un site vitrine multipage complet pour FASH'LINK en utilisant uniquement :
- HTML
- CSS
- JavaScript (sans framework)

Palette :
- Fond blanc (#FFFFFF)
- Texte noir (#000000)
- Accents sombres (#111111, #222222, #333333)

Typographie :
- Montserrat (Google Fonts)
- Style minimaliste, mode/fashion

Icônes :

Contenu requis :

SECTION 2 — Comment ça marche

1. L’utilisateur remplit un formulaire (bx-edit)  
2. L’admin vérifie et valide (bxs-badge-check)  
3. Le profil devient visible (bx-show)  
4. Le styliste peut être contacté (bx-chat)

- 120 stylistes partenaires  
- 300 jeunes talents inscrits  
- 850 missions publiées  
- Icônes : bx-user, bx-group, bx-briefcase, bx-check  

SECTION 4 — Avantages

- Connexion directe talents ↔ stylistes (bx-link-external)  
- Processus sécurisé (bx-lock)
